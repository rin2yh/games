# ジャッジメントダイス

Ebitengine で実装したサイコロゲーム。遊戯王の「ジャッジメントダイス」と、動画配信者「タンクトップ小隊」を題材にした 3 つのモードを収録。

## モード

1. **遊戯王ジャッジメントダイス** — サイコロを振り、出目 1〜6 に対応する効果を表示。
2. **タンクトップ小隊のジャッジメントダイス** — CPU と同時にサイコロを振り、相手より小さい目を出せば勝利。
3. **タンクトップ小隊ジェンガモード** — 1 ならこちらのターン、2〜6 なら相手のターンを判定。

## 操作

キーとクリック / タップのどちらでも遊べる。

| シーン | キー | クリック / タップ | 動作 |
| --- | --- | --- | --- |
| タイトル | `1` / `2` / `3` | 選択肢の行 | 各モードへ遷移 |
| 共通 | `ESC` | 左下の「← タイトル」 | タイトルへ戻る |
| 効果モード | `SPACE` | 画面 | ダイスを振る |
| 効果モード | `R` | — | リセット |
| 対戦 / ジェンガ | `SPACE` | 画面 | 開始 / 次の勝負 |

## 構成

```
cmd/judgement-dice/main.go   エントリポイント
internal/judgementdice/game/ ゲームロジック（Dice / Duel / Jenga / Effects）
```

入力は `internal/judgementdice/game/input.go` でキーとポインタを `input` 型に
まとめてから各シーンに渡している。シーン側はどちらで操作されたかを見ない。
タイトルの選択肢は表示・キー・当たり判定を 1 つの表 (`titleItems`) から出して
いるので、モードを足すならそこだけを触る。

## 実行

```sh
GAME=judgement-dice mise run serve-game
```
